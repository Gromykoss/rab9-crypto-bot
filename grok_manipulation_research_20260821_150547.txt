# RAB9: инструкция по манипуляциям мемкоинов  
**(мониторинг бота, не статья)**

Два контура — **разные часы и разные пороги**. Их нельзя смешивать.

| Контур | Объект | Окно сигнала | Главный враг |
|---|---|---|---|
| **A. Отбор** | тысячи CA (pump.fun / аналоги) | минуты–часы | bundle / sniper-кольца / wash / KOL-ферма |
| **B. Слежение** | выбранный токен (BURNIE, MC ~$1–2M) | минуты–дни | ложный пробой коридора, скрытая раздача, «разогрев» без новых покупателей |

Проблема сейчас: фазу видим постфактум. Правило RAB9: **пробой — гипотеза**, пока не подтверждён фильтрами ниже. Уже в коде: `candidate → confirmed | failed | liquidity_test`; полный отчёт только если аномалия **удержалась на следующем тике** (±20% price-watch).

---

## 1. Полный цикл манипуляции

Оператор не «рисует график» — он **перекладывает предложение** между своими руками и розницей.

### Фаза 1. Накопление
**Что делает:** тихо собирает флоат в коридоре; иногда spring (ломает поддержку), чтобы стряхнуть слабых.

**Признаки (контур B):**
- коридор ≥3–7 дней (`flat_days`);
- объём на падениях сжимается (предложение впитывается);
- холдеры растут медленно; топ-10 **не раздувается**;
- крупные кошельки покупают мелкими клипами, в разные часы, с разной историей;
- X почти молчит («мёртвый график»).

**Вердикт:** ранний вход, ещё успеваем. Единственная дешёвая фаза.

### Фаза 2. Пробой / тест ликвидности
На 5–15m выглядят одинаково:
1. **Настоящий пробой (SOS)** — спрос шире предложения, диапазон сломан.
2. **Ложный (upthrust / liquidity test)** — тык сопротивления, сбор стопов/FOMO, возврат в коридор.

**Правило:** не переименовывать фазу в `markup`, пока статус ≠ `confirmed`.

### Фаза 3. Разогрев / markup
Оператор **уже внутри**. Нужны чужие деньги: объём, KOL, DexScreener boost, «умные кошельки», которые все трекают.

**Признаки:** цена выше коридора; холдеры растут; vol/MC резко вверх; X: CA в тренде, reply-спам.

**Вердикт для B:** докупать опасно. Ждать откат к бывшему сопротивлению **только если** топ не раздаёт.

### Фаза 4. Раздача / exit
График ещё может быть зелёным.

**Признаки сильнее цены:**
- боковик/слабое снижение + **рост холдеров** = раздача новым;
- волнами сливают 20+ связанных кошельков;
- топ-10 → свежие кошельки → сразу sell;
- LP худеет;
- KOL-пост **после** импульса = exit liquidity, не катализатор.

## 2. Паттерны pump.fun (контур A — hard-gate до слежения)

### 2.1 Sniper vs Bundle
- **Sniper:** бот в 1–5 блоках после create. Конкуренция.
- **Bundle (Jito):** create + пачка buys в **том же слоте**, tip валидатору. Окно для розницы = 0.  
  Свежий X (`@Bubblemaps` / $PENSION): первые снайпы в том же Jito-бандле, что и create → ~$140k net у оператора.

**Правило A:** `bundle_pct ≥ 20%` ИЛИ ≥3 buys в блоке #1–2 → **REJECT / не в слежение**.  
MemeTrans: high-risk = короче sale, меньше buyers, больше per-buyer, сильнее skew; после группировки бандлов топ-10 у high-risk растёт сильнее (~+24 п.п. медианы).

### 2.2 Bundling + volume farming (wash)
Бандл даёт 60–95% саплая на 20–50 кошельках. Farming: те же кошельки крутят объём друг через друга → trending DexScreener/BullX/Photon.

| Смотрим | Детект | Значение |
|---|---|---|
| Buys в том же блоке, что create | Solscan / Trench / RugCheck / Pump.fun indicator | pre-capture supply |
| Fresh wallets (возраст минут) | история кошелька пустая до buy | бандл-кошелёк |
| Общий funder | SOL-трейс → один источник / CEX | один оператор |
| Vol↑, holders flat | Δholders / Δvol низкий | wash / farming |
| Круглые размеры, ровный ритм | одинаковые SOL-клипы, интервалы | бот-farm |
| Те же адреса buy+sell | кластер по обе стороны | wash |

**Пороги A (отбор):**
- топ-10 (после де-бандла) > 50% → high risk;
- один кошелёк > 10% (не LP/curve) → флаг;
- first buy > 5% supply → insider;
- 3+ buys в block #1–2 → bundle almost certain;
- vol24 высокий при Δholders ≈ 0 → wash-подозрение.

### 2.3 KOL-памп / CT extraction
Свежий X: один deployer (`yHCxHB…`) гоняет пачку personality-тикеров ($ANSEM/$TJR/$LUKE…), «65% to X», розница празднует «культуру».

| Смотрим | Детект | Значение |
|---|---|---|
| Пачка KOL за 15–60 мин | X-радар: N упоминаний от ≥3 KOL | заказной разогрев |
| Нет #ad / disclosure | по умолчанию считать paid | BEARISH bias |
| KOL после +50–100% | timestamp vs price | exit liquidity |
| Аккаунты <7 дней, одинаковые шаблоны | age + text similarity | vote/engagement spam |
| Deployer с 10+ предыдущими CA | история create | serial extractor → REJECT |

### 2.4 Rug / exit liquidity
Stair-step / slow drip / single dump / LP unlock.  
На mid-cap вроде BURNIE чаще **drip + KOL**, не мгновенный rug.

## 3. Настоящий пробой vs ложный (ядро для контура B)

Литература: **60–70%** первых пробоев сопротивления — ложные; после накопления smart money успех резко выше.  
RAB9 уже кодирует статусы — инструкция задаёт **семантику алертов**.

### 4 фильтра подтверждения (все нужны для «настоящий»)

1. **Объём:** на пробойной свече `breakout_volume_ratio ≥ 2.0` к 14d средней (у вас уже `rel_vol_14d ≥ 2` для `smart_money_breakout`). Слабый порог «интереса» = ×1.5; ниже ×1.5 при цене у сопротивления = шум.
2. **Закрытие, не фитиль:** close выше сопротивления. Фитиль + close внутри = `liquidity_test` (upthrust).
3. **Удержание следующего бара/тика:** следующая свеча/тик **не** закрылась обратно в коридор → `confirmed`. Иначе `failed`. Совпадает с price-watch: короткий алерт → полный отчёт только если удержалось.
4. **Ончейн до/во время пробоя (не после):**
   - buy_ratio ≥ 1.3 (лучше ≥ 1.5) на окне 15–60m;
   - топ-10 **не уменьшает** суммарный % (или уменьшает <2 п.п.);
   - число холдеров растёт, не только объём;
   - нет волны sells с известных бандл/кабал-кластеров;
   - kabals ≤ 2 и не sell-heavy (`trading_theory`).

### Ложный пробой — три типа

| Тип | Объём | Ончейн | Действие RAB9 |
|---|---|---|---|
| Retail FOMO | высокий, но без роста холдеров / без крупных buys | топ уже полный или продаёт | `failed` / тишина после отката |
| Stop-hunt / upthrust | огромный шип → мгновенный разворот | sells над сопротивлением | `liquidity_test` → ждать spring/retest |
| News/KOL spike | пик на посте, потом сушка | нет накопления до события | не поднимать фазу |

**Правило входа после пробоя (B):** не на первом шипе. Ждать откат 20–40% импульса к бывшему сопротивлению (теперь support) + buy_ratio держится + топ не раздаёт. Это отсекает большинство фейков.

**Для BURNIE:** «пробой 10%» — не сигнал (урок хронологии). Рабочие: **±20% / 10m** как аномалия-кандидат + подтверждение удержанием; для markup — `breakout_status=confirmed` + vol×≥2.

## 4. Ончейн-метрики ЗАРАНЕЕ (до выхода из накопления)

Сигналы «ещё успеваем» vs «уже внутри / поздно»:

### Ещё успеваем (ранний)
| Метрика | Порог / правило |
|---|---|
| Цена в коридоре, vol на даунах ↓ | bullish divergence (уже в `chart_analysis`) |
| Мелкие неоднородные buys | разные размеры, разные funders, не один блок |
| Топ-10 стабилен или чуть ↓ за счёт LP/curve | концентрация не растёт |
| Holders +медленно при flat price | тихое накопление |
| Creator не продаёт ≥7d | conviction (theory) |
| Kabals buy-heavy при MC mid + early lifecycle | bullish (theory) |
| X тихий | stealth accumulation |

### Smart money уже внутри / опаздываем
| Метрика | Порог / правило |
|---|---|
| Кластер fresh wallets купил крупно за ночь | пример X: $CASHCAT +$2.7M cluster → «coordinated?» |
| Tracked «smart wallets» массово в холдерах | часто наживка после входа кабала |
| Vol×≥2 + цена уже над коридором | markup начался |
| Top-10 растёт при росте цены | накопление закончилось / контроль |
| Buy/sell ≈ 50/50 при огромном vol/FDV | bot PvP churn, не накопление (пример $GUNICORN) |
| Smart traders net outflow | раздача, не набор |
| Kabals buy-heavy при MC>1M late | exit liquidity trap (theory) |

### Раздача (срочно)
- топ-холдеры клипают sell волнами;
- holders↑ + price flat/down;
- creator dump >20% initial;
- MC/LP > 20× → проскальзывание / ловушка выхода;
- serial deployer / один кластер на серии тикеров.

## 6. Карта аномалий для монитора RAB9

Формат: **что смотрим → как детектируем → что значит**.

### Контур B (BURNIE / выбранный токен)

**A1. Объёмный шип у сопротивления**  
→ `rel_vol_14d ≥ 2` и цена у верхнего свинг-хая коридора (не ATH)  
→ кандидат на пробой; статус `candidate`, не менять фазу.

**A2. Фитиль выше сопротивления, close внутри**  
→ `breakout_status=liquidity_test`  
→ тест ликвидности / upthrust; ждать возврат; не BUY.

**A3. Close выше + удержание следующего бара/тика**  
→ `confirmed` + buy_ratio≥1.3 + holders↑ + топ не dump  
→ настоящий пробой / markup; алерт «пробой подтверждён».

**A4. Close выше, следующий бар вернул в коридор**  
→ `failed`  
→ ложный пробой; тишина или «ложная тревога».

**A5. Цена ±20% / ~10m**  
→ price-watch фаза 1 → короткий алерт; фаза 2 удержалась → полный трекер  
→ аномалия в моменте (уже внедрено).

**A6. Vol↑ ×2+, holders flat, те же адреса buy/sell**  
→ wash_suspicious / низкий Δholders/Δvol  
→ farming / разогрев без спроса; не трактовать как markup.

**A7. Топ-10 суммарно −≥5 п.п. за 1–4h при зелёном графике**  
→ holder snapshot diff  
→ раздача в розницу; SELL/REDUCE bias.

**A8. Kabal/cluster sell-heavy, buy_ratio<0.5**  
→ wallet_intel / cabal_detector  
→ координированный dump; AVOID / эскалация.

**A9. X mentions spike без onchain buys**  
→ radar_x vs DexScreener buys  
→ fake buzz / KOL-заказ.

**A10. Bullish divergence в коридоре (price↓/flat, vol↑ на поглощении)**  
→ `smart_money_accumulation`  
→ ранний foreshadow пробоя; ещё успеваем.

### Контур A (отбор CA)

**B1. Bundle ≥20% / same-slot buys** → REJECT  
**B2. Fresh wallet cluster + common funder** → REJECT  
**B3. Top-10 >50% после de-bundle** → REJECT / high risk  
**B4. Serial deployer (personality/CT conveyor)** → REJECT  
**B5. Wash: high vol, flat holders, round clips** → FLAG  
**B6. KOL swarm <60m post-launch без disclosure** → FLAG, не вход без ончейна

## 8. «Рано» vs «поздно» — шпаргалка для алертов

**РАНО (ещё успеваем):**
- накопление + vol divergence bullish;
- A10 без пробоя цены;
- тихий X, растущие «живые» холдеры мелкими клипами;
- creator hold, kabals не sell-heavy;
- bundle/wash clean на истории запуска (для новых CA).

**ПОЗДНО (smart money внутри / раздача):**
- `confirmed` уже несколько баров назад + KOL только сейчас;
- tracked smart wallets «внезапно» в топе после импульса;
- vol×3–5 при holders flat (wash) или топ клипает sell;
- CT/KOL swarm + green candles + top distribution;
- serial cabal-тикер / «65% to influencer».

**Золотое правило монитора:**  
сначала ончейн (holders, top-10 delta, buy_ratio, bundle/cluster), потом объём/пробой, потом X.  
X первым = почти всегда опоздание или заказной разогрев.

## 9. Что это значит для текущих модулей RAB9 (без кода, только логика алертов)

1. **`chart_analysis`:** `liquidity_test` / `failed` не эскалировать в «разогрев»; `confirmed` без ончейн-фильтров 4 — только «технический пробой», не «smart money breakout».
2. **`burnie_price_watch`:** ±20% = детектор **момента**; полный отчёт = только после удержания (уже так). Добавить в текст отчёта: holders/top10/buy_ratio/X, иначе снова постфактум.
3. **`cabal_detector` / `wallet_intel`:** на mid-cap следить за **дельтой** топ-кластеров за 1–4h, не только фактом присутствия.
4. **`radar_x`:** классифицировать mentions: organic / KOL-paid / spam; paid+dumping top = BEARISH даже при зелёной цене.
5. **Контур A (будущий отбор):** hard REJECT на bundle/serial deployer до любого DeepSeek-анализа — иначе MoA будет рационализировать график бандла.

### Короткий итог
Манипуляция мемкоина — это контроль **предложения** (бандл/кластер) + контроль **внимания** (wash + KOL).  
На BURNIE война идёт за отличие **теста ликвидности** от **подтверждённого пробоя**: объём ×2 у сопротивления + close + удержание + ончейн (buy_ratio, холдеры, топ не сливает). Всё остальное — либо рано копить, либо уже опоздали.
